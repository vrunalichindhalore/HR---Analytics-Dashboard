# HR Analytics Dashboard

## Project Overview
This project is an interactive HR Analytics Dashboard developed using Power BI. It helps analyze employee data and provides insights into workforce performance, attrition, salaries, education, and other HR metrics.

## Tools Used
- Power BI
- Microsoft Excel

## Features
- Employee Attrition Analysis
- Department-wise Analysis
- Job Role Analysis
- Gender Distribution
- Age Group Analysis
- Education Analysis
- Salary Analysis
- Interactive Filters and Slicers
- KPI Cards and Charts

## Key Insights
- Analyzed employee attrition trends.
- Compared departments and job roles.
- Evaluated salary and performance distribution.
- Built interactive KPI dashboards using Power BI.  

## Dataset
The project uses an Excel dataset (`HRData 1.xlsx`) containing employee information.
