
# 📊 HR Analytics Dashboard (Power BI)

## Project Overview
This project is an **Interactive HR Analytics Dashboard** developed using **Microsoft Power BI**. The dashboard provides comprehensive insights into employee data, workforce performance, attrition trends, salaries, education, and other key HR metrics. It enables HR teams to make data-driven decisions through interactive visualizations and dynamic filtering.

## Features
- 📈 Interactive HR Dashboard
- 👥 Employee Attrition Analysis
- 🏢 Department-wise Analysis
- 💼 Job Role Analysis
- 💰 Salary Distribution Analysis
- 🎓 Education-wise Employee Analysis
- 🚻 Gender Distribution
- 🎂 Age Group Analysis
- 📊 KPI Cards (Total Employees, Attrition Rate, Average Age, Average Salary)
- 🎛️ Interactive Filters and Slicers
- 📉 Dynamic Charts and Visual Reports

## Tools & Technologies
- Microsoft Power BI
- Microsoft Excel
- Power Query
- DAX (Data Analysis Expressions)
- Data Cleaning & Transformation
